Instructions

There is a little setup you must do, one time, before you can use this extension.

  1. Add this extension to Chrome (you probably already did, if you're seeing this)
  2. Create an Integration on Developer Portal
    • Redirect URI is in this format: 
      https://{{Chrome Extension ID}}.chromiumapp.org/
      , where the Chrome Extension ID can be found in your Chrome Extension Manager for this extension.
    • Scopes should be set to: 
      cjp:user cjp:config cjp:config_read cjp:config_write
  3. Update the Client ID and Client Secret below
  4. Create an Entry Point for Inbound Telephony, filling in the required fields (values mostly don't matter), and you do not need a phone number on it
  5. Copy the Entry Point ID into the field below
  6. Create at least one Outdial ANI list and add at aleast one phone number to it (or use what you already have)
  7. Copy that phone number into the field below (+e164 format, and it doesn't actually make a phone call, just used for validation)
  8. Click Save

Once you've done the above, then each time you click the extension icon, while looking at a published flow, the extension will map the flow to the Entry Point, then execute the Flow. After you click the button, check the Flow debugger and see that your flow executed.
